evidence layer
agent runCurrent prompt, model, tools, and config attempt the task.
trace adapteretrace, Langfuse, LangSmith, or custom spans normalize to Trace.
eval runnerExact match, LLM judge, tool count, no-error, and cost scorers.
distillationRoot cause, suggested fix, fix type, and target component.
failure records
fix_type routing
candidate
repair layer
gepaOptimizes system prompt, tool policy, answer format, and verification policy.
agent optimizerProposes code, tool, and config fixes when the issue is agent-side.
holdout gateAccepts only if quality improves without unsafe cost or transfer regression.
promotionThe accepted candidate becomes the next baseline.
